# FinTrack

A full-stack personal finance management platform.

## Description

FinTrack is a web application designed to help users manage their personal finances.

## Planned Features

- User authentication
- Income and expense tracking
- Categories
- Budgets
- Savings goals
- Financial analytics
- Recurring transactions
- Notifications
- AI financial assistant
- Admin dashboard

## Technology

- React
- TypeScript
- Node.js
- Express
- PostgreSQL
- Tailwind CSS
- Git
- GitHub
